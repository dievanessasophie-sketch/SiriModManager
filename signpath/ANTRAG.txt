Siri ModManager is a free Windows desktop application for the siri-mods.de
community. It helps users discover, install, update and remove mods for Transport
Fever 2 and Transport Fever 3, with separate installation paths for both games.
It is written in Go and uses the Windows API directly. There are no external Go
module dependencies, bundled advertisements or analytics SDKs.

The application source, build scripts, resources and project documentation are
prepared for public release under the MIT license. Downloaded game mods
and the separate server are not part of the software being submitted for signing.
The ModBase service requires a registered and approved forum account. Desktop
authentication takes place through the normal browser with PKCE and scoped device
tokens; the application does not collect the forum password.

We request code signing for two binaries built from this repository:
SiriModManager.exe and SiriModManager_Setup.exe. The prepared GitHub Actions
workflow builds on GitHub-hosted Windows runners, requests the manager signature,
verifies it, embeds that exact signed binary into the installer, then requests
the installer signature. Separate test and release policies are planned, with
manual approval for each signing request.

The repository includes a code signing policy, privacy information, uninstall
instructions and third-party notices. We would configure origin verification,
MFA and protected signing access according to the Foundation's requirements.

This is our first Foundation application. The prepared workflow has not yet been
run against a Foundation certificate. Please let us know if further project
history, review or configuration is required for acceptance.
