# Security reports

Report suspected security issues privately to **mail@siri-mods.de**. Include the
manager version, affected feature and steps to reproduce. Remove access tokens,
passwords and personal data before sharing logs. Do not post credentials in issues.

The project uses HTTPS origin restrictions, browser-based authorization with PKCE,
Windows DPAPI for local tokens, per-device server access and staged mod replacement.
These mechanisms do not replace review or Windows and live-server testing.

Version 0.8.0 is the currently maintained source line. There is no paid support SLA.
